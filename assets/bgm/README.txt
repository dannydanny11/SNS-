이 폴더에 BGM 음원(mp3 / m4a / wav)을 넣어두세요.
쇼츠를 만들 때마다 이 폴더에서 한 곡을 랜덤으로 골라 자동 삽입합니다.
(폴더가 비어 있으면 BGM 없이 영상이 만들어집니다.)

■ 반드시 지킬 것 — 저작권
  · '본인이 라이선스를 보유한' 음원 또는 '로열티프리(상업적 사용 가능)' 음원만 넣습니다.
  · 저작권 있는 일반 상업 음원(가요/팝 등)은 절대 넣지 마세요. Content ID 에 걸려
    수익이 저작권자에게 넘어가거나 영상이 차단/삭제됩니다.

■ 구독형(Artlist / Epidemic Sound 등)을 쓰는 경우
  · 라이선스가 있어도 Content ID 는 클레임을 겁니다.
  · Artlist/Epidemic 계정 설정에서 '본인 유튜브 채널'을 화이트리스트(연동) 등록하면
    해당 채널 영상의 클레임이 자동 해제됩니다. 업로드 전에 반드시 등록하세요.

■ 다른 곡으로 고정하고 싶으면
  · .env 에  SHORTS_BGM=C:\경로\곡.mp3   (특정 파일 고정)
  · .env 에  SHORTS_BGM=C:\경로\폴더      (그 폴더에서 랜덤)
  · 지정 안 하면 이 기본 폴더(assets/bgm)를 사용합니다.
